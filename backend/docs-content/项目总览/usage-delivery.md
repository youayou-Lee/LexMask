# 使用与交付

本页只给总览；每一步怎么点、每个按钮什么作用，见对应的操作指南。

## 三个入口

| 入口 | 适合 | 说明 | 操作指南 |
|---|---|---|---|
| 单次处理 | 一份文件，先验证效果 | 默认为法律卷宗口径；可调识别范围 | [[single-file|单文件处理]] |
| 批量处理 | 几十到上千份，同一套口径 | 批量打码；化名需逐份走单次 | [[batch|批量处理]] |
| 供料模式 | 案卷转脱敏 Markdown 交给 AI | 单文件仅 PDF；批量供料支持 PDF / Word / 文本 / 扫描件 | [[feed-agent|供料模式]] |

## 两种产物

- **传统模式（原格式成品）**：打码或替换后的成品文件；附化名对照表（仅供人工核对，不随成品外发）；批量支持 ZIP 分卷与页账。导出与交付细节见 [[export-delivery|导出与交付]]。
- **供料模式三件套**：脱敏 Markdown + 映射表 + 保留字段清单；映射表可在还原工具中还原。细节见 [[feed-agent|供料模式]]。

两种模式的定位见 [[delivery-modes|两种模式]]；当前不支持哪些组合见 [[current-limits|当前能力边界]]。
