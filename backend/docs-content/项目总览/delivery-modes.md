# 两种模式

| | 传统模式（原格式成品） | 供料模式 |
|---|---|---|
| 输出 | 可归档、可提交的成品文件（PDF / Word / 图片），该遮的遮、该换的换 | 脱敏 Markdown + 映射表 + 保留字段清单 |
| 给谁 | 法院、客户、对方律师、监管、公众 | 下游 AI 程序 / 大模型 / Agent |
| 还原 | 不提供还原入口（化名对照表仅供人工核对） | 凭映射表可在还原工具中还原 |
| 流程 | 上传 → 识别 → 复核 → 处置 → 导出 | 上传 → 解析 → 识别 → 确认映射 → 生成三件套 |

两种模式用的是**同一套识别能力**，区别只在产物形态。同一份材料可以两种都出。

操作细节见 [[usage-delivery|使用与交付]]；供料模式的完整说明见 [[feed-agent|供料模式]]。
