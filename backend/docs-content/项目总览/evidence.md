# 证据与可信度

## 分级

| 等级 | 定义 | 用途 |
|---|---|---|
| E1 | 客户环境可当场复跑 | 可对外承诺 |
| E2 | 我方环境可复跑，有脚本与台账 | 可对外，必须带条件 |
| E3 | 一次性验收记录（特定版本 / 硬件 / 语料） | 仅内部参考，不进对外材料 |
| E4 | 无出处 / 已撤回 | 禁用 |

## 可对外的质量事实（E2）

- 三行业黄金语料 12 份、107 个标注实体；直接标识符 **67/67 命中**（法律 31、医疗 19、金融 17）；类型正确率 **97–100%**。
- 该语料与门槛常驻代码库，是构建门槛：识别管线改动导致 identity 召回下降即构建失败。
- 可复跑入口见公仓评测脚本（随版本演进，以仓内为准）。

## 性能：为什么不做承诺

本文**不给出**「每秒 / 每页 / 每份」的对外承诺。原因是：同一功能在不同硬件、不同文档类型、不同页密度下差异可达数十倍；任何单点秒数离开条件都没有意义。

条件化的实测记录见《性能与质量白皮书》§3，每条都绑定日期、构建与语料；其中属一次性验收的记录不得用于对外承诺。对外一律以**客户环境实测**为准。

## 已撤回 / 禁用数字

- 白皮书 v1.1 已正式撤回两组早期性能数字（「份/分钟」吞吐与「秒/份」单文件耗时），任何材料不得再用。
- 历史验收中的整卷相对提速、单页最坏值、批量份数、库表导出耗时等，均属 E3 一次性记录，仅内部参考，不进对外材料。

数字的使用规则见 [[terminology|术语与口径]]；性能上的不承诺见 [[quality-boundaries|质量与性能边界]]。
