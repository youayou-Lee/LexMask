# 差异与壁垒

| 对比对象 | 它的做法 | 墨隐的差异 |
|---|---|---|
| 人工打码 | 逐页手动，尺度不一，漏了不知道 | 同原文全文同名、可复核、页账可查、批量一致 |
| 在线脱敏 SaaS | 上传到云端处理 | 数据不出域、可断网；视觉链路（印章 / 签字 / 证件）本地做 |
| 通用大模型直接改 | 让模型读原文、直接生成「脱敏版」 | 模型只找不改；改文确定性执行；映射可核；失败页隔离 |
| 拼装方案（OCR + 正则 + LLM） | 零件各自为战，没有复核与账本 | 三链路融合 + 复核工作台 + 页级账本 + 两种产物 |

一句话：**别人卖的是「打码按钮」，墨隐卖的是「可核查、可交付的链路」。**
