# 行业定位

产品定位是**全行业**：底座与行业无关，识别、复核、处置、交付四层能力不绑定任何行业；行业差异只体现在**识别项组合、处置口径与合规话术**，不在引擎。

**当前版本（v1.0）聚焦法律场景**：法律预设最完整，操作文档与默认流程以法律文书为主。内置四套行业预设：法律（14 类识别项）、医疗（18）、金融（16）、政务（11）；医疗、金融、政务可直接用预设或自定义清单，后续版本逐步补齐行业化能力。

预设与识别项细节见 [[capability-map|能力地图]]；当前限制见 [[current-limits|当前能力边界]]。
