# 产品简介

本产品是一套部署在您自己服务器或内网中的文档脱敏工作台：上传文件后自动识别敏感信息，您逐条复核确认，再打码或替换成化名，导出可以对外提供的成品；需要交给 AI 时，还可以输出结构化供料。原始文件始终留在您的部署环境里。

完整定义、产物形态与行业范围见 [[overview|项目总览]]，特别是 [[product-definition|产品定义]] 与 [[delivery-modes|两种模式]]。

## 三种主要使用形态

| 形态 | 入口 | 适合 |
|---|---|---|
| 单文件处理 | 左侧导航「单次处理」 | 一份文件，先验证识别效果 |
| 批量处理 | 左侧导航「批量处理」 | 一次几十到上千份，按同一套口径处理 |
| 供料模式 | 左侧导航「供料模式」 | 案卷转成脱敏 Markdown，交给云端 AI |

详细操作见 [[single-file|单文件处理]]、[[batch|批量处理]]、[[feed-agent|供料模式]]。

## 第一次使用

1. 用「单次处理」处理一份真实但不涉密的材料，确认识别类型是否符合预期；
2. 到「高级设置 → 识别项设置」调整不需要脱敏的类型（见 [[entity-types|识别项设置]]）；
3. 按 [[quick-start|快速开始]] 走完第一份文件的完整流程；
4. 口径确认后，再进入批量处理。
