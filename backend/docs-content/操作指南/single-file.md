单文件处理（左侧导航「单次处理」）是最常用的入口：一份文件从上传到成品，全程在一个页面里完成。它同时也是验证识别口径最好的地方——口径不对，改一次设置，再处理下一份即可。

## 一、上传与自动识别

1. 进入「单次处理」；
2. 把文件拖进虚线框，或点击选择文件；
3. 上传成功后**自动识别开始**，无需额外点击。

上传后如果提示输入 PDF 密码，说明该文件设了打开密码。密码只用于本次解密，不会被保存。

识别期间页面会显示阶段条（文档预检 → 逐页识别 → 后台加速）与进度数字。请不要刷新页面；确需离开时可以先切走，回来通常还能接着看。

## 二、识别范围：查什么由您定

上传区的「识别范围」决定了这次要查哪些类型，分三个区：

- **语义识别**：从正文里找姓名、证件号、案号这类文本信息；
- **文字有无检测**：逐页检查扫描件里出现了哪些敏感字样；
- **视觉特征定位**：定位印章、签名、手写批注等页面视觉要素。

每个区里可以勾选具体类型，也可以搜索。常用组合可以点「保存为方案」，起个名字（如「执行案件初查」），下次直接选。

> 识别范围在上传文件的那一刻就固定了。识别开始后想换，请点「调整识别项」回到上传页重新选择。

## 三、复核：这一步决定成品的准确度

复核区通常左右分栏：左边原文或页面图，右边敏感项清单。

**文本类文件（Word、纯文本）**：左侧显示原文与高亮，右侧是敏感项清单。点击某一项可以在小窗里「移除标注」；在正文里选中文字可以补充标注。

**PDF 与图片**：左侧是逐页页面图，识别到的内容已自动定位成框。每个框上有来源标签：

| 标签 | 含义 |
|---|---|
| 识别 | 系统自动定位的框 |
| 手动 | 您自己拉框补充的框 |
| 图片文字 | 画面里识别出的印刷文字（扫描件、图片） |
| 正则 | 按格式规则匹配到的（如固定格式的编号） |

在右栏「区域列表」里可以逐项勾选或取消；在图上选中框可以删除；遗漏处直接在图上拉框。所有框（不论来源）在打码时都会被遮盖。

## 四、选择处理方式

### 打码（仅 PDF / 图片）

打码就是**直接把内容遮盖掉**，没有子选项。文本型 PDF 选打码后，页面切换为与扫描件一致的图像工作台：识别内容已自动成框，所见即所打。打码画的框切到「替换」再切回来仍然保留，但只有打码执行时使用框。

（批量处理第一步另有「清晰标签 / 自然替换 / 直接掩码」三种文本呈现形式可选，单次处理不提供。）

### 替换（化名）

选这项后会出现「化名映射」表，系统已按默认规则生成替换词：

- 每行 = 原文 ｜ 类型 × 次数 ｜ 替换词输入框（可修改）；
- **每一行都必须有替换词**，清空某行会导致「开始匿名化」按钮变灰；
- 两行填了同一个替换词时会出现黄色提醒。这只是提醒，不影响执行——如果两个写法（如公司全称与简称）您想统一，填同一个词即可；
- 点「重新识别」会刷新自动映射，但**您手动改过的行保持不变**。

默认化名规则举例：张三 → 张某1（同姓第二人 → 张某2）；某某科技有限公司 → 某公司1；北京市海淀区… → 某市某区某街道…；身份证号、手机号、银行卡号 → 位数与校验都合法的虚构值。

中央级机关（如最高人民法院、司法部）、国际组织、出版物与媒体名称默认保留原文，因为名称本身公开、无脱敏必要。确需替换时，在该行手动填一个词即可覆盖。

## 五、执行与结果

点「开始匿名化」，按钮上会显示本次要处理的敏感项数量。完成后进入结果页：

- **成品 / 对照**两个视图可以切换，成品视图就是您将下载的样子；
- **质量报告**：结果页「详情」里的核对项，交付前怎么用见 [[export-delivery|导出与交付]]；
- **下载文件**：获取成品；
- **下载化名对照表**（替换模式）：原文 / 类型 / 化名 / 出现次数，Excel 直接打开不乱码；
- **处理新文件**：开始下一份。

结果页的「返回编辑」可以回到复核视图继续调整。

## 六、两个实用开关

- **成品水印（可选）**：在右侧「高级」抽屉里填写水印文案（如「仅供 XX 项目使用」，默认收起，点开即可），导出的 PDF / 图片成品会叠加半透明平铺水印；留空不加，预览不受影响；
- **原始水印处理**：部分 PDF 自带防泄漏水印层。系统可以选择「保留」或「识别前自动摘除、成品不带原水印」（仅 PDF，默认保留）。检测到可摘除的水印时，上传后会给出提示。

## 七、中断与恢复

处理中途切到别的页面、刷新浏览器，识别与化名映射结果通常不会丢（超长文档除外）。若提示「已恢复上次单文件处理现场」，说明现场已从服务端取回。

切换处理另一个文件时，系统会询问是否替换当前现场；未执行的编辑不会保留。
