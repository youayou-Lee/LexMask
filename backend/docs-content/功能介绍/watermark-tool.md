# 水印检测

对外提供 PDF 前，如果文件带防泄漏水印或平铺水印，用「水印检测」生成一份净化副本。

## 入口

左侧导航「水印工具」。

## 流程

1. **上传 PDF**：一次一份；
2. **检测报告**：显示检测到的水印情况；检测失败会显式提示，不会静默跳过；
3. **摘除**：确认后生成净化副本；
4. **下载**：下载的是新的净化件，**原件不会被修改**。

## 什么时候用

- 案卷、合同、报告对外提供前，需要去掉原文自带的防泄漏水印；
- 需要保留正文与版式，只去掉水印层。

## 注意

- 仅支持 PDF；
- 净化件是独立副本，原文件保持原样；
- 摘除后请按交付流程抽查一遍版式与内容。
