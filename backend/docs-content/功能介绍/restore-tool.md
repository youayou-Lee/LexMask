# 还原工具

供料模式出稿后，如果授权人员需要回到原文核对，用「还原工具」把脱敏文本还原回来。

## 入口

左侧导航「还原工具」。

## 输入与输出

| 项 | 说明 |
|---|---|
| 输入 1 | 脱敏文本（`.txt` / `.md`），即供料模式产出的脱敏 Markdown |
| 输入 2 | 映射表（`.json`），与脱敏文本同批下载 |
| 输出 | 还原后的文本（`restored.md`） |

两个文件都选好后点「还原」，页面会显示还原结果并可下载。

## 什么时候用

- 供料模式出稿后，需要核对某一处占位符对应原文；
- 授权范围内需要把结构化供料还原成可读文本。

## 注意

- 映射表与原件同等保密，**不要随成品一起外发**；
- 还原是授权行为，请按机构内部规定执行；
- 没有映射表就无法还原——映射表请与脱敏文本分开保管。
