成品怎么拿、怎么交给别人、交付前该检查什么，都在这一篇。导出这一步做对了，前面的复核才算真正落地。

## 单文件：下载什么

单文件处理完成后，结果页提供：

- **下载文件**：成品本身（打码后的 PDF / 图片，或替换后的文档）；
- **下载化名对照表**（替换模式）：四列——原文 / 类型 / 化名 / 出现次数，Excel 直接打开不乱码；
- **质量报告**：实体总数、已匿名化数量、未处理数量、来源分布、映射记录、版本记录，以及失败页提示。

质量报告不是摆设。交付前扫一眼「未处理实体」和「有失败页或任务失败」两项，比事后被对方挑出来强得多。

## 批量：完整导出还是选页导出

批量任务确认完成后进入导出，有两种模式：

| 模式 | 内容 | 适用 |
|---|---|---|
| 完整导出 | 全部成功页与人工补框页，主产物直接打包 | 常规交付 |
| 选页导出 | 只导出您勾选的页 | 只需要其中几页，或主产物还没生成 |

选页导出会在识别仍在进行时也能用：它拿的是当下这一刻的快照，所以页面上会提示「识别仍在进行中」。勾选时只有成功页可选，失败页与未跑页不可选，也不会进包。

## 导出包里有什么

一个典型的批量导出包包含：

- 脱敏后的成品文件（按原目录结构组织）；
- 映射清单（替换/化名对应关系，便于核对）；
- 可选的「说明.txt」：逐条列出被排除的页号与原因码。

正文 PDF 里不含任何插入页，说明信息只在包内的说明文件里。

## 失败页不会混进成品

这是设计上的硬约束，值得单独强调：

- 识别失败的页**不会**被当作干净页打进包里；
- 失败的页会在导出界面和说明文件里逐条列出；
- 如果查询不到是否有失败页，系统会中止提交，而不是赌一把。

看到失败页清单时，正确做法是回任务详情单独重试那几页，再重新导出；不要直接交付一个「少了几页」的包。

## 大批量：分卷导出

超过 200 份时，导出会自动切换为异步分卷：

1. 点导出后先秒回预估大小；
2. 系统后台打包，完成后逐卷列出下载入口；
3. 每卷不超过 2GB，逐卷下载后合并解压；
4. 导出过程可以离开页面，完成会有提示。

导出记录会保留在页面上，可以回看之前生成的包及其校验值。

## 交付前的检查清单

1. **口径**：识别类型是否符合本案要求（该脱的脱了、不该脱的没脱）；
2. **完整性**：有没有失败页、有没有漏掉的文件；
3. **可读性**：替换模式下版式是否还能正常阅读，化名是否前后一致；
4. **对照表**：化名对照表是否与成品分开保管；
5. **敏感级**：对照表、说明文件与原件同等敏感，不要随成品一起外发。

## 水印与标识

批量向导第一步和单文件处理页都可以填写**成品水印**（如「仅供 XX 项目使用」）。水印平铺在导出的 PDF / 图片上，预览不受影响。对外提供材料时建议填写，便于追溯外流版本。

## 交付之后

- **处理结果**：左侧导航「任务中心」可以回看历史任务、重新下载成品；
- **回收站**：删除的文件保留 7 天，可以还原或彻底删除，超期自动清除；
- **还原工具**：替换模式下，用映射表可以还原出原文（需要相应权限），用于内部核对。

## 常见问题

- **下载的文件打不开**：确认下载完整（大文件分卷时要全部下载后再解压）；
- **成品里还有敏感信息**：先看质量报告的「未处理实体」，再回编辑视图补框或调整识别项，重新导出；
- **改了复核结果但导出没变**：确认是否点过确认/保存，未保存的修改不会影响导出。
