一份一份处理案卷太慢时用批量处理（左侧导航「批量处理」）。它是一条五步向导：选择清单 → 上传 → 批量识别 → 审阅确认 → 导出。

批量处理的关键特点是**先统一口径、再逐份复核、最后统一交付**。前面慢一点，后面省很多。

## 第一步：选择识别清单

选一份清单决定这一批要查哪些类型：

- **行业预设**：金融行业、法律行业、医疗行业、政务行业，开箱即用；
- **自定义清单**：在「高级设置 → 配置清单」里自己组合，或直接在这一步调整识别项。

选好清单并确认后才进入上传。清单在这一步固定，后续想改要回到这一步重来。

成品水印文案也在这**第一步**里填写（可选），导出时平铺在成品上。

## 第二步：上传

支持批量拖入多个文件，也可以：

- **从服务器目录导入**：文件已经在平台服务器上时，不必经过您的电脑上传。在导入对话框里刷新、勾选、导入即可，每个账号只能看到自己子目录的文件；
- **远程服务器拉取**：同一对话框切到远程服务器标签，填主机、账号、目录后直接浏览并拉取，全程不经过办公电脑。

大文件会自动分块续传。传输过程中的闪断由分块续传自动接续；上传失败的卡片上点「重试失败文件」即可重传该文件，不必重新选择。

## 第三步：批量识别

提交后进入后台队列，进度实时可见。您可以离开页面，识别完成后会有页内提示；如果浏览器页签在后台，还会发系统通知（首次使用需要允许通知权限）。

识别进行中不必干等：**已经完成的文件可以先审阅**，不必等全部跑完。

## 第四步：审阅确认

逐份复核识别结果，确认无误后点确认：

- 快捷键：**← / →** 切换文件，**Ctrl+Enter** 确认当前文件；
- 需要修改时，直接在复核视图里勾选、取消、拉框补充；
- 已获授权的账号可以用一键确认剩余全部跳过逐份复核（按钮上会显示剩余份数）。这是不可撤销的操作，会有二次确认弹窗；
- 没有「批量确认」权限时按钮是灰的，需要管理员在「权限信息」里为您的账号开启。

审阅过程中可以随时看任务中心（左侧导航「任务中心」）了解整体进度、待复核数量和异常文件。

## 第五步：导出

确认完成后进入导出：

- 打包下载全部成品；
- 超过 200 份时自动切换为后台分卷导出：先秒回预估大小，再逐卷下载，每卷不超过 2GB；
- 可以附带质量报告与明细 CSV。

## 部分文件失败怎么办

批量任务中，单份文件或单页失败不会拖垮整批：

1. 在任务详情里查看失败的文件与页（页格中标红的格子）；
2. 失败页不会自动进入成品包；勾选「在包内附带说明.txt」后，说明文件会逐条列出页号与原因；
3. 需要重跑时，对失败文件点重试，或在页格详情里单独重试某一页。

不要因为个别文件失败就整批重跑——重跑会覆盖已确认的结果，得不偿失。

## 批量处理的限制

| 限制 | 说明 |
|---|---|
| 不支持替换（化名） | 批量只做打码。化名需求请逐份走单次处理 |
| 整批口径统一 | 同一批使用同一份清单；不同案件类型请分批 |
| 确认需要权限 | 「批量确认」由管理员按账号授予 |
| 分卷导出 | 超过 200 份自动分卷，需逐卷下载后合并解压 |

## 批量供料（喂给云端 AI）

批量向导还提供「供料」通道：上传 PDF、Word、文本与扫描件，逐份转成脱敏 Markdown，确认映射表后整批导出，附还原用的映射表。适合要把整批案卷投喂给云端 AI 做摘要或要素抽取的场景。

单文件场景直接用左侧「供料模式」更方便，详见《供料模式（喂 Agent）》。
