这里按「用不下去」「结果不对」「导不出来」三类整理高频问题。先在这里找，找不到再联系管理员或技术支持——报问题时附上文件名、页号与页面截图，定位会快很多。

## 登录与账号

### 忘记密码、登录不上怎么办

联系管理员重置密码或重新开通账号。系统没有自助找回，这是有意的设计。

### 「批量确认」按钮为什么是灰的

需要管理员在「系统设置 › 权限信息」里为你的账号开启「批量确认」权限。没有这项权限时，每份文件都要单独确认。

### 只读账号为什么什么都点不了

只读角色按设计仅可查看。请管理员调整角色。

### 换了电脑，设置还在吗

账号级的识别项开关与清单保存在服务端，换电脑依然有效。页面上临时保存的「方案」以及浏览器里的部分选择不保证跨设备保留，换设备后首次处理时重新选一次即可。

## 识别结果不对

### 识别漏了怎么办

在复核视图手动补：文本视图选中文字添加标注；页面视图直接在图上拉框。补完再执行。

如果大面积漏识别，多半是识别范围不对——点「调整识别项」回上传页换清单或勾选识别项，重新识别一次。

### 识别多了、把不该脱的也脱敏了

- 单条：文本视图点该项，在小窗里点「移除标注」；页面视图在「区域列表」取消勾选或删除框；
- 整类：去「高级设置 → 识别项」关掉对应识别项的「启用」，或在上传时选一份不含它的清单。

### 某类信息我根本不想脱敏（例如开庭时间）

在「高级设置 → 识别项」里找到对应识别项，关闭「启用」。设置对本账号所有处理生效，一次设置长期有效。出生日期与一般日期是独立识别项，关掉「日期」不影响出生日期。

### 法院、部委、杂志名为什么没被替换

中央级机关（含最高人民法院、司法部等）、国家部委、国际组织、出版物与媒体名称默认保留原文——名称本身公开，没有脱敏必要。地方法院、地方机构照常替换。确需替换时，在化名映射表那一行手动填一个词即可覆盖。

### 同一个化名在不同文件里不一样

这是预期行为。化名一致性只在单个文件内成立；不同文件里同一个人可能是不同化名，不影响脱敏效果。

### 表格里孤零零一个出生日期，会漏吗

有可能。这类信息靠上下文判断，排版特殊时可能识别不到。成品下载后请抽查表格页。

## 处理方式

### 纯文本 / Word 文件为什么没有打码选项

打码（遮盖）只对 PDF 与图片开放。Word 和纯文本请用「替换（化名）」，敏感词会换成化名或 `<姓名[001]>` 这样的标签，同样达到脱敏效果。

### 扫描件能用化名替换吗

目前不支持。扫描型 PDF 与图片只能用打码。这是能力边界，不是配置问题。

### 文本型 PDF 选打码后，左侧怎么变成一张张页面图

这是预期行为。打码必须落在页面坐标上，所以文本型 PDF 选打码后会切换到与扫描件一致的图像工作台，识别内容已自动成框，可直接勾选、删除、拉框补充。需要文档保持可读请改选「替换（化名）」。

### PDF 打码后为什么文字选不中

打码成品是整页转为图片的 PDF，原文字不可再选中、复制，也不会残留隐藏文字——脱敏更彻底。这是预期效果。

### 化名映射表填了同一个词会出问题吗

两个不同原文填同一个替换词时会出现黄色提醒。这只是提醒，不影响执行。如果公司全称与简称您想统一，填同一个词即可。

### 「开始匿名化」按钮为什么点不了

两种常见原因：替换模式下有行没填替换词（把化名映射表填齐）；或所有敏感项都被移除了（点「重新识别」恢复）。按钮下方通常会有对应提示。

## 导出与交付

### 导出提示分卷

正常现象。大批量导出会自动分卷（每卷不超过 2GB），逐卷下载后合并解压即可。

### 导出包里少了某几页

先看导出界面的失败页清单与包内说明文件。识别失败的页不会被当作干净页打进包，这是刻意设计。正确做法是回任务详情单独重试那几页，再重新导出。

### 成品和预览看起来不一致

替换按您确认的映射执行；个别因排版原因（跨行、词中夹空格）定位不到的位置可能替换不到位。下载后请抽查一遍成品，必要时回编辑视图补框。

### 导出很慢 / 一直排队

导出是后台任务，大批量或页数多时排队属正常。可以先做别的，完成会有提示。若长时间无变化，联系管理员查看服务状态。

## 其他

### 上传失败

先确认格式在支持范围内（Word、纯文本、PDF、图片）；.rtf 请勿使用。扫描型 PDF 识别较慢，请耐心等待。文件与扩展名不匹配时系统会明确提示。

### 识别要跑很久

扫描件、图片、超大版式的文件耗时会更长；服务排队时也会等。进度页显示的是真实完成数与已用时间，不要反复刷新或重复提交。几百页的案卷按小时计是正常的。

### 支持哪些文件格式

Word（.doc / .docx）、纯文本（.txt / .md / .html）、PDF（文本型与扫描型）、常见图片格式（.jpg / .png / .bmp / .gif / .webp / .tif）。.doc 上传后成品输出为 .docx。

### 怎么看版本号

页面左下角可见版本号与构建时间。反馈问题时请一并提供。

### 识别某页失败、页格是红的

点该页的格子查看「第 N 页发生了什么」详情（只看原因，不会触发重试）。确认原因后在详情面板点「重试这一页」。识别没跑完或任务已进入终态时该按钮不可用。

### 数据会不会外泄

识别与处理全部在您的部署环境内完成，原始文件不离开内网。日志只记录处理过程（哪一页、走了哪条路、耗时、失败原因），不记录案卷内容；成品包里不含日志。日常使用请照常遵守本单位的文件管理规定。
