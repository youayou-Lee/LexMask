## 本产品是什么

本产品是一套部署在您自己服务器或内网中的法律文书脱敏工作台。上传判决书、笔录、合同、证据材料之后，系统自动识别其中的姓名、证件号、地址、机构、账户等敏感信息；您逐条复核确认后，把它们打码或替换成化名，再导出可以对外提供的成品。

原始文件始终留在您的部署环境里，不经过任何第三方服务——这也是它与在线脱敏工具最本质的区别。

## 它解决什么问题

律师和法务把案卷交给法院、客户、对方律师或其他外部机构时，通常要隐去当事人的姓名、身份证号、住址、银行账号等信息，但又必须保留案件事实、时间脉络和法律关系。手工遮盖费时、容易漏，也很难复核。

本产品把这件事变成一条可复核、可留痕、可重复的流程：

- **自动识别**：不必逐页用眼睛找；
- **人工复核**：每一处识别结果都可以勾选、删除、补充；
- **两种产物**：打码（遮盖）或替换（化名），按用途选择；
- **可核对**：替换模式附带化名对照表，审阅人可以核对是否脱敏到位；
- **可追溯**：处理结果集中管理、操作留痕，管理员可导出审计日志。

## 三种主要使用形态

| 形态 | 入口 | 适合 |
|---|---|---|
| 单文件处理 | 左侧导航「单次处理」 | 一份文件，先验证识别效果 |
| 批量处理 | 左侧导航「批量处理」 | 一次几十到上千份，按同一套口径处理 |
| 供料模式 | 左侧导航「供料模式」 | 案卷转成脱敏 Markdown，交给云端 AI 做摘要、审阅、要素抽取 |

此外还有还原工具（用供料模式的映射表还原原文）、水印工具（上传 PDF 检测并摘除水印）等小模块。库表处理、医学影像去标识化暂未开放（入口从导航隐藏，仅保留内部路由）。

## 谁在用

- **律师**：向客户或法院提供脱敏版卷宗；
- **法务**：对外提供合同、证据材料前的合规处理；
- **律师助理、实习生**：批量处理案卷、整理脱敏材料；
- **信息技术与合规人员**：负责账号、识别口径与审计。

## 界面上的几个固定位置

- **左侧导航**：所有功能的入口；
- **左下角**：版本号、构建时间，以及本地模型服务状态（文字识别、文本语义、视觉特征三个服务是否在线）；
- **右上角**：修改密码、切换语言与退出登录；
- **任务中心**：所有批量任务与供料任务的进度、复核和下载入口。

左下角显示的服务状态值得看一眼：显示「可用」时放心提交；显示「需处理 / 不可用」时先联系管理员，不要反复重试。

## 建议的第一次使用

1. 先用「单次处理」处理一份真实但不涉密的材料，看看识别出来的类型是否符合预期；
2. 到「高级设置 → 识别项设置」调整不需要脱敏的类型（单次处理默认查「法律卷宗」组合，本就不含事件日期，出生日期在查）；
3. 再按《快速开始》走完第一份文件的完整流程；
4. 确认口径无误后，再进入批量处理。
