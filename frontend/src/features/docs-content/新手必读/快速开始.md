本篇带您把第一份文件完整走一遍。全过程通常几分钟到十几分钟，视文件大小而定；其中大部分是系统在跑，您真正需要动手的只有「复核」这一步。

## 第一步：登录

1. 打开管理员给您的平台地址（形如 `http://<云平台地址>:<端口>`）；
2. 输入管理员开通的账号和密码登录；
3. 第一次登录后，建议点右上角「修改密码」改掉初始密码。

登录后如果左下角显示「全部服务正常」，说明识别服务已就绪，可以开始。文件按账号隔离：您上传的文件只有您自己能看到。

## 第二步：看清支持的格式

| 格式 | 打码 | 替换（化名） |
|---|---|---|
| .txt / .md / .html / .htm（纯文本类） | 不支持，请用替换 | 支持 |
| .docx / .doc（Word 文档） | 不支持，请用替换 | 支持 |
| .pdf（文本型） | 支持 | 支持 |
| .pdf（扫描型） | 支持 | 不支持 |
| .jpg / .jpeg / .png / .bmp / .gif / .webp / .tif / .tiff（图片） | 支持 | 不支持 |

两条硬性提醒：

- **打码只对 PDF 和图片开放。** Word 和纯文本文件上传后没有打码选项，这不是故障；
- **.rtf 请勿使用**：实测确认脱敏不彻底，成品可能残留敏感信息。

单个文件大小默认不设上限；如果部署时设置了上限，超限会提示上传失败或文件过大（视入口而定）。

## 第三步：上传并等待识别

进入左侧导航「单次处理」，把文件拖进虚线框（或点击选择）。上传成功后系统**自动开始识别**，不需要您再点任何按钮。

进度会分成几段显示：文档预检 → 逐页识别 → 后台加速。大文件、扫描件、服务排队时耗时会更长，请不要刷新页面。识别完成后页面会自动切到复核视图。

## 第四步：复核识别结果

右栏列出识别到的敏感项（类型 + 原文），左侧是原文高亮或页面图：

- **保留**：确认无误的直接保留；
- **移除**：文本视图点该项，在小窗里点「移除标注」；页面视图在右栏「区域列表」取消勾选，或选中框后删除；
- **补充**：识别遗漏的，文本视图选中文字即可添加；页面视图直接在图上拉框。

识别类型不符合预期时，点「调整识别项」回到上传页重新选择识别范围，再上传识别一次。

## 第五步：选择处理方式并执行

- **打码**（仅 PDF / 图片）：遮盖敏感内容，可选结构化标签、智能替换、掩码替换三种呈现形式；
- **替换（化名）**：把敏感词换成虚构词，文档保持可读。选这项后要在「化名映射」表里逐行确认替换词——每一行都必须有替换词，否则「开始匿名化」按钮是灰的。

点「开始匿名化」，按钮上会显示本次要处理的敏感项数量。

## 第六步：下载成品

完成后在结果页点「下载文件」。替换模式还会有「下载化名对照表」。点「处理新文件」可以开始下一份。

结果页的「对照」视图可以把原文与成品并排比对；「成品」视图就是您将下载的样子。

## 接下来做什么

- 识别出来的类型太多或太少 → 看《识别项设置》与《配置清单》；
- 文件太多一份一份处理太慢 → 看《批量处理》；
- 想弄清某个框、某种视图是干什么的 → 看《预览与调整》；
- 需要把成品交给别人 → 看《导出与交付》，尤其注意失败页的处理方式。

## 小提示

处理中途切到别的页面或刷新浏览器，识别与化名映射结果通常不会丢（超长文档除外），回来即可继续。真的丢了，重新上传一次即可。
