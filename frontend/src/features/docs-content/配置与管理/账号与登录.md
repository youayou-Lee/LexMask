这一篇讲账号从哪来、密码怎么改、谁能做什么，以及文件是怎么隔离的。日常使用只需要看前三节，后面几节是给管理员和信息技术同事的。

## 怎么拿到账号

- 平台是私有部署的，地址由管理员提供（形如 `http://<云平台地址>:<端口>`），请按本单位规定使用；
- 部署后的第一个注册账号自动成为管理员；
- 之后的账号由管理员在「系统设置 › 权限信息」里创建，或者开放自助注册（自助注册的账号默认是普通角色）。

登录页只需要账号和密码。公用电脑上用完请退出登录。

## 修改密码

点页面右上角「修改密码」，验证当前密码后设置新密码。修改后本次登录保持有效，其他设备上的登录会随即失效。

忘记密码或登录不上，只能联系管理员重置——系统不提供自助找回，这是有意的设计。

## 文件是隔离的

您上传的文件、生成的成品、任务记录，只有您自己的账号能看到。管理员可以在控制台查看用户与文件列表用于排障，但日常使用中不同账号互不可见。

团队协作时请注意：需要共享的成品请通过正常的交付渠道发出，不要指望在平台里互相「看到」对方的文件。

## 五种角色能做什么

| 角色 | 能做什么 |
|---|---|
| 管理员 | 全部功能，外加用户管理、系统配置、审计日志、授权许可 |
| 审核员 | 完整处理流程；可被额外授予「批量确认」 |
| 普通用户 | 同审核员 |
| 操作员 | 上传、识别、导出；**不能**确认审核 |
| 只读 | 仅查看，不能上传、不能导出 |

两个常见困惑：

- **「批量确认」按钮是灰的**：需要管理员在「权限信息」里为您的账号单独开启「批量确认」；
- **只读账号点什么都没反应**：这是角色的设计，请管理员调整角色。

## 服务状态与授权

- 左下角常驻显示本地模型服务状态（文字识别、语义识别、视觉识别）。出现异常时先联系管理员，不要连续重试；
- 授权到期前 30 天，登录页会出现提醒横幅；到期后进入只读宽限期——数据可以查看、可以导出，但不能新建任务。

## 管理员功能一览

- **权限信息**：创建账号、分配角色、为指定员工开启「批量确认」、禁用账号；
- **运行配置**：调节任务并发数；
- **审计日志**：按用户、动作、关键字检索「谁在何时上传、确认、导出了什么」，可导出 CSV；
- **服务监控**：模型服务状态、显卡内存与数据盘水位；
- **授权许可**：查看授权状态、到期日、席位；上传续期证书后立即生效，无需重启。

## 账号禁用与回收站

- 管理员可以禁用账号：禁用后该账号立即无法登录，已登录的会话也随即失效；不能禁用自己或最后一个管理员；
- 删除的文件会进入回收站，保留 7 天，可以还原或彻底删除，超期自动清除。

## 企业登录（LDAP / AD）

由部署工程师在服务端配置启用。启用后，员工用域账号密码登录，角色按 AD 组自动映射；管理员始终可以用本地账号登录，作为目录服务故障时的兜底。

## 常见问题

- **换了电脑，设置还在吗？** 账号级的识别项设置存在服务端，换电脑依然有效；页面上的临时勾选（如识别范围）不保证跨设备保留；
- **提示账号已禁用**：联系管理员确认；如果是误操作，重新启用后即可登录；
- **登录后提示只读**：授权可能已到期，或账号角色为只读，联系管理员处理。
