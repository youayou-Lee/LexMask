识别清单（也叫配置清单）是一份「勾选好的识别项组合」。建好一次，处理同类型案件时直接选用，不必每次手动勾选。

## 它解决什么问题

案件类型固定时，识别口径往往也固定：劳动争议案要看入职时间、工资数额、公司名称；交通事故案要看车牌、驾驶证、保险信息；民间借贷案要看借条金额、转账记录。

如果没有清单，每次上传都要重新勾选一遍，既慢又容易漏。清单把这套口径固化下来。

## 系统内置清单

「高级设置 → 配置清单」里已经放了几份现成方案，覆盖常见行业：

- 金融服务
- 法律案卷
- 医疗记录
- 政务公开

这些清单可以直接用，也可以复制一份再改——复制后不影响原清单。

## 怎么建一份自己的清单

1. 左侧导航「高级设置」，进入「配置清单」页签；
2. 点新建，给清单起一个能看懂的名字（如「交通事故案」「执行初查」）；
3. 把需要的识别项勾上（车牌、驾驶证、地址……）；
4. 保存。

建议按案件类型建 2–3 份，而不是为每个案子新建一份。清单太多反而记不住用哪份。

## 处理文件时怎么选

- **单次处理**：在上传区的「识别范围」处选清单；不选清单时按账号的「默认识别范围」处理；
- **批量处理**：向导第一步选清单，整批统一使用；
- **供料模式**：沿用账号的默认识别范围。

顺序很重要：**先选清单，再点开始识别。** 清单在识别开始的那一刻就固定了。

## 识别完才发现选错了

点识别结果右侧识别卡片上的「调整识别项」，确认后回到上传页重新选择清单或勾选识别项，再上传识别即可。

这个动作只影响当前文件，不会改动其他文件，也不会改动账号级设置。

## 清单与账号开关的区别

| | 配置清单 | 账号级识别项开关 |
|---|---|---|
| 管什么 | 这一次查哪些类 | 允不允许查、默认查不查 |
| 生效范围 | 单次任务 | 本账号的所有任务 |
| 什么时候改 | 每次处理前 | 一次设置，长期生效 |

两者配合使用：账号开关处理「永远不需要」的类型，清单处理「按案件类型变化」的类型。

## 与「保存为方案」的关系

单次处理上传区的「识别范围」弹窗里也可以「保存为方案」，保存后出现在「我的方案」里。方案和配置清单解决的是同一类问题，区别在于入口和使用习惯：

- 在上传页临时调整后顺手保存 → 用「方案」；
- 想集中管理、给同事统一口径 → 用「高级设置 → 配置清单」。

不必两边都建。选一种您顺手的即可。

## 常见问题

- **清单改了，之前处理过的文件会变吗？** 不会。清单只影响之后新提交的处理；
- **清单里某项勾不上、显示「已停用」**：该识别项在账号级被停用了，去「高级设置 → 识别项」把「启用」打开；
- **清单能导出给别人吗？** 识别项与清单支持导出，便于在团队内统一口径；
- **批量处理能用不同清单吗？** 一批任务共用一份清单。口径不同的文件请分成两批。
