# 产品定义

**一句话**：墨隐把文件里的敏感信息找出来，遮掉或换成化名，输出仍然是你原来的文件格式；同一份文件还可以额外生成一份给 Agent 读的结构化文本。

## 定义

墨隐是一套部署在用户自己服务器或内网中的**文档去标识化工作台**。它处理 Word、PDF（含扫描件）、图片与纯文本，自动识别其中的姓名、证件号、地址、机构、账户、印章等敏感信息；用户逐条复核确认后，把敏感信息**打码**或**替换**，导出可以直接对外使用的成品；对需要交给 AI 处理的场景，还可以输出结构化供料。

原始文件始终留在用户自己的部署环境里，不经过任何第三方服务。这是它与在线脱敏工具最本质的区别。

产物形态见 [[delivery-modes|两种模式]]；行业范围见 [[industry-positioning|行业定位]]。

## 不是什么

- **不是匿名化产品**：映射表可还原，见 [[not-anonymization|不是匿名化]]。
- **不是云服务 / SaaS**：本地或内网部署，模型与数据都不出域，见 [[architecture|技术与架构]]。
- **不是通用大模型的套壳**：模型只负责「找」，改文由确定性规则执行，见 [[architecture|技术与架构]]。
- **不是只做法律**：当前版本聚焦法律，但产品定位是全行业，见 [[industry-positioning|行业定位]]。
- **不是单一打码工具**：可复核、可审计、可批量、可供料，见 [[differentiation|差异与壁垒]]。
