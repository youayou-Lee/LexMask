# 术语与口径

## 术语表

| 词 | 含义 | 怎么用 |
|---|---|---|
| 脱敏 | 对敏感信息做遮蔽或替换的统称 | 对外主词 |
| 去标识化 | 处理后不借助额外信息无法识别，但借助映射可复原 | 法律 / 技术定语；我们的准确定位 |
| 匿名化 | 无法识别且不能复原（个保法第 73 条） | 只出现在边界说明，不自我描述 |
| 传统模式 | 保持原文件格式的成品交付 | 与「供料模式」并列 |
| 供料模式 | 输出 MD + 映射表 + 保留清单，供 AI 消费 | 正式材料统一叫「供料模式」 |
| 映射表 | 原文与占位符 / 化名的对照 | 与成品分开保管 |
| 保留清单 | 供料模式中选择保留原文的字段 | 只属供料模式 |
| 页账 | 页级成功 / 人工 / 失败 / 未跑记录 | 交付审计 |
| 打码 / 替换 / 化名 | 遮盖 / 换成占位符或同类词 / 替换的一种 | 不用「匿名化」代称 |

术语的法律依据见 [[not-anonymization|不是匿名化]]。

## 禁用词

- 匿名化（例外：[[not-anonymization|不是匿名化]] 这一篇的边界说明）
- 百分百合规 / 完全合规
- 零风险 / 绝对安全 / 彻底删除 / 不可复原
- 「AI 自动脱敏，无需人工」（人工复核是流程的一部分）

## 数字使用规则

1. 只引用 E1 / E2；
2. 每个数字必须带条件（版本、硬件、语料、测量方法）；
3. 不用个案冒充基准，不把不同量纲的数字并列；
4. E3 数字只在内部台账，E4 数字禁用。

证据分级见 [[evidence|证据与可信度]]。
