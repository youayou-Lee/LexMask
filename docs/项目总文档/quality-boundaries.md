# 质量与性能边界

## 质量边界

- **不保证零漏检**：机器识别有概率漏掉特殊排版、断行、夹空格、手写、图片内文字。**人工复核与成品抽查是流程的一部分，不是可选项。**
- **不保证版式完全一致**：替换成品经文档中转可能细微重排；版式要求高请用打码。
- **不保证跨文件化名一致**：一致性只在单个文件内成立。
- **不提供法律意见**：脱敏范围是否充分由用户判断。

## 性能边界

不承诺固定耗时。同一功能在不同硬件、不同文档类型、不同页密度下差异可达数十倍；对外一律以客户环境实测为准。

为什么不做性能承诺、以及哪些数字已被撤回，见 [[evidence|证据与可信度]]；当前功能限制见 [[current-limits|当前能力边界]]。
