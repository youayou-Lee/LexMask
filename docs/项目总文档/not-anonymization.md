# 不是匿名化

《个人信息保护法》第 73 条：匿名化是指个人信息经过处理**无法识别特定自然人且不能复原**的过程；第 4 条：匿名化后的信息不属于个人信息。

墨隐交付映射表，化名与占位符可以还原——这在法律上属于**去标识化**，不是匿名化。因此：

- 对外只用「脱敏 / 去标识化」，不用「匿名化」自我描述；
- 如客户需要匿名化（不可复原），应在交付后销毁映射表，并由客户侧完成剩余风险评估。
